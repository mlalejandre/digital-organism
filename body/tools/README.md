# Tools Directory

This directory contains custom scripts and utilities to assist Nail-35b-a3b in executing complex tasks.

Supported formats:
- `.sh` (Bash)
- `.py` (Python)
- `.js` (Node.js)

Current Tools:
- `self_test.py`: Basic environment and logic verification.
- `system_health.py`: Checks directory structure and file existence.
- `logger.py`: Writes timestamped messages to `memory/agent_log.txt`.

Usage:
Use the `EXECUTE` capability to run these scripts.
